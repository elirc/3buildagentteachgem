# Architectural Cartographer Suite

Welcome to the Architectural Cartographer Suite for the Agentic Education Operations platform. This suite is designed to be your primary technical onboarding manual, written from the perspective of a senior engineer mentoring a developer they genuinely want to see succeed. 

## Purpose
The goal is not to list facts. The goal is to teach you *how this system thinks*. We will progressively drill down from high-level mental models into folder structures, data flows, routing mechanics, type contracts, and advanced feature architectures. 

## How to Use This Suite
This suite is designed to be read sequentially, mapping to your growing familiarity with the codebase. Do not skip around until you have completed the linear progression.

### Recommended Reading Order
1. **`00-reading-map.md`**: Start here. This provides the 10,000-foot view of the architecture and the exact sequence of the top 10 files you should read in the repository.
2. **`01-junior-engineer.md`**: Focuses on orientation, local setup, essential vocabulary, and foundational anatomies of frontend components and backend actions.
3. **`02-mid-level-engineer.md`**: Explores complex topics including state management, API contracts, full-stack data traces, and non-obvious architectural patterns.
4. **`03-senior-engineer.md`**: Focuses on ownership. Includes architectural critiques, security and performance audits, bug injection exercises, and refactor planning.
5. **`04-reference-suite.md`**: A permanent, consolidated reference document covering debugging playbooks, change management, and code review checklists.

## Socratic Checkpoints
Throughout `01`, `02`, and `03`, you will encounter "Socratic Checkpoints". These are not quizzes; they are active learning validation tools. 
When you reach a checkpoint:
1. Stop reading the guide.
2. Open the codebase and attempt to answer the questions out loud or on a whiteboard.
3. Immediately review the "How to self-grade" rubric provided directly below the questions to assess your understanding. 

Treat these checkpoints with rigor. They are the difference between passive reading and active comprehension.
