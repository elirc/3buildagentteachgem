# Mission Learning Path Suite

Welcome to the Mission Learning Path. This suite is not documentation to be read passively; it is an active training campaign. You are not reading—you are executing missions to build your muscle memory and intuition within this specific codebase.

## How to Use This Suite
Each mission forces you to trace code, answer questions, review logic, debug issues, or explain patterns. 

1. **Start sequentially:** Do not skip tiers. If you are a senior engineer, the Junior missions will take you exactly 4 minutes, but they will establish the baseline domain context you need for the Senior missions.
2. **Open your IDE:** You cannot complete these missions in a browser. You must have the code open.
3. **Do not pause:** When you reach a Socratic Checkpoint, answer the questions out loud or on paper. Immediately after, read the self-grading rubric. Do not ask a mentor until you have graded yourself.

## The Mission Structure
Every mission follows this exact format:
- **Goal:** One sentence defining success.
- **The Concept:** A domain-specific analogy or mental model.
- **Design Intent Before You Read the Code:** What to expect and what failure looks like.
- **Find It In The Code:** The exact files and line ranges you must open and trace.
- **The Aha Moment:** The core insight you should walk away with.
- **Socratic Checkpoint:** 5 questions and a self-grading rubric.
- **Connects To:** Where this knowledge applies next.

Your training begins in `01-tier-1-junior-missions.md`. Good luck.
